ชื่อในเมนู AddOns: Alphaverse THAI SUB
ชื่อโฟลเดอร์และไฟล์ตั้งค่าภายใน: ForeverThai (ใช้ร่วมกับเวอร์ชันเดิมได้)

Alphaverse THAI SUB 0.462.0 — ติดตั้งบน Mac M2

ใช้ไฟล์ ZIP ของ ForeverThai ชุดเดียวกับ Windows ได้
ส่วนที่เกมโหลดเป็น Lua, TGA และ TTF ไม่ต้องรันโปรแกรม Windows ของเครื่องมือพัฒนา
ต้องมีไคลเอนต์ Forever ที่รองรับ Interface 16001 และภาษาอังกฤษ enUS/enGB
เทียบซอร์ส UI และจำลอง Tracker ของ Forever 1.60.1 build 70790, 70862 และ 70888
การทดสอบบน Mac M2 ยังรอดำเนินการ

1. ปิดเกมก่อนอัปเดต
2. ใน Battle.net เลือก Forever กดรูปเฟือง แล้วเลือก Show in Finder
3. เปิด _forever_/Interface/AddOns/ หากยังไม่มี Interface หรือ AddOns ให้สร้างเอง
4. แตก ZIP แล้วคัดลอกเฉพาะโฟลเดอร์ ForeverThai ที่มี ForeverThai.toc ไปยัง AddOns
   ต้องได้ Interface/AddOns/ForeverThai/ForeverThai.toc ไม่มีโฟลเดอร์ซ้อนอีกชั้น
   คงชื่อไฟล์และโฟลเดอร์ Fonts ตามเดิม โดยเฉพาะดิสก์ที่แยกตัวพิมพ์เล็กกับใหญ่
5. เปิดเกม เปิด ForeverThai ในเมนู AddOns ที่หน้าตัวละคร แล้วเข้าเกม
6. พิมพ์ /fth image แล้ว /fth test ควรเห็น “น้ำค้างยามเช้า” ใช้ /fth hide ปิดหน้าทดลอง

อ่านเอกสารและหนังสือ

เปิดเอกสารหรือหนังสือที่รองรับตามปกติ หน้าต่างภาษาไทยจะเปลี่ยนตามหน้าที่เกมเปิด

แปลแถบติดตามเควสด้านขวา

ใช้กับแถบติดตามเควสของเกมหรือ Questie สำหรับ Forever เปิดตัวเลือกใน Settings > AddOns > ForeverThai
ติ๊ก Translate Quest Tracker to Thai หรือพิมพ์ /fth tracker on
เอาติ๊กออกหรือพิมพ์ /fth tracker off เพื่อกลับเป็นภาษาอังกฤษ
ค่าเริ่มต้นเป็นภาษาอังกฤษและเกมจะจำตัวเลือกนี้ไว้ พิมพ์ /fth tracker เพื่อเปิดหน้าตั้งค่า
เมื่อมีคำแปลที่ตรวจแล้ว จะแสดงชื่อและเป้าหมายย่อยเป็นไทย พร้อมระดับและตัวนับของเกม
ข้อความที่ยังไม่มีคำแปลจะแสดงเป็นอังกฤษ แถบของเกมจะใช้อังกฤษด้วยหากบรรทัดไทยยาวเกินพื้นที่
ถ้าสลับตัวเลือกขณะต่อสู้ ให้รอจนออกจากการต่อสู้เพื่ออัปเดตทั้งแถบ


หากไม่มีเมนู AddOns ให้ตรวจระดับโฟลเดอร์ในข้อ 4 แล้วปิดและเปิดเกมใหม่
ค่าเริ่มต้น /fth image ใช้ภาพคำภาษาไทยที่จัดสระและวรรณยุกต์ไว้แล้ว
โหมด /fth font ในตัวจำลองยังมีอักษรไทยเป็นสี่เหลี่ยม หากพบให้กลับด้วย /fth image
ไม่ต้องส่งโฟลเดอร์ WTF หรือข้อมูลบัญชีของ Windows ให้ผู้รับ
คำแปลที่ยังไม่มีหรือข้อความสดที่ต่างจากแหล่งที่ตรวจจะยังไม่ถูกแปล
ยังไม่ยืนยันเควสชุดใหม่ การเลื่อนด้วยเมาส์จริง หรือผลในเกมบน Mac M2

หากเปิดสมุดเควสแล้วพบเป้าหมายย่อยที่ยังแปลไม่ได้ Addon จะเก็บต้นฉบับไว้ใน SavedVariables บนเครื่อง ดูจำนวนได้ด้วย /fth capture
พิมพ์ /fth capture log เพื่อเก็บชื่อ เป้าหมายหลัก คำอธิบาย และข้อความพร้อมส่งที่ยังไม่มีคำแปลจากรายการในสมุดเควสที่เกมเปิดให้อ่าน
หากต้องการเก็บอัตโนมัติเมื่อสมุดเควสอัปเดต ให้พิมพ์ /fth capture auto on และปิดได้ด้วย /fth capture auto off
ตัวเลือกนี้ปิดไว้เป็นค่าเริ่มต้น และเก็บข้อมูลในเครื่องเท่านั้น
สำหรับเควสที่ยังขาดเป้าหมายหรือคำอธิบาย คำสั่ง capture log จะบันทึกสถานะช่องที่เกมส่งมาในสมุดเควส
เมื่อเปิด capture auto จะเก็บสถานะจากหน้ารับเควส ระหว่างทำ และตอนส่งด้วย ข้อมูลอยู่ใน questPanels ของไฟล์ SavedVariables
สถานะระบุว่าช่องนั้นมีข้อความ ว่าง หรือมีแต่ช่องว่าง เกมที่ยังไม่ส่งค่าจะไม่มีสถานะ ข้อมูลนี้อ้างอิงเฉพาะหน้าที่เปิด

กล่องบทพูด NPC ภาษาไทย (ชุดทดลอง)
เมื่อ NPC พูดบรรทัดที่มีคำแปลตรงกัน กล่องซับไทยจะขึ้นทันทีด้านล่างกลางจอ
แสดงสองบรรทัดเหตุการณ์ล่าสุด และปิดเองหลังข้อความล่าสุด 15 วินาที ลากย้ายได้
ใช้ภาพตัวอักษรไทย ไม่อาศัยการวาดภาษาไทยของ client กล่องต้นฉบับยังแสดงตามเดิม

/fth speech on       เปิด (ค่าเริ่มต้น)
/fth speech off      ปิดและซ่อนกล่อง
/fth speech test     ทดสอบกล่องและตัวอักษร ไม่ใช่การยืนยันข้อความจาก NPC จริง
/fth speech hide     ซ่อนข้อความปัจจุบัน
/fth speech capture on   เก็บต้นฉบับบทพูดที่ยังแปลไม่ได้ไว้ในเครื่อง (ปกติปิด)
/fth speech capture off  หยุดเก็บต้นฉบับ
ข้อมูลที่เก็บอยู่ใน ForeverThaiObserved.speech ใน SavedVariables/ForeverThai.lua
อาจมีชื่อผู้เล่นที่ NPC เรียก เก็บในเครื่องเท่านั้น ไม่มีการส่งออกอัตโนมัติ
จำกัดบทพูดใหม่ 512 รายการ / 256 KiB และใช้เพดานรวมเดิมร่วมกับบันทึกเควสต์

ขอบเขต: รองรับเหตุการณ์ NPC say/yell/whisper/emote บน client อังกฤษ build70862/70888
คำแปลเริ่มต้นมี 12 บรรทัดอ้างอิง Classic ของ Escorting Erland และคำพูด Arynia ใน Mist
จะใช้ต่อเมื่อ NPC ID และต้นฉบับทั้งบรรทัดตรงเท่านั้น ยังไม่ยืนยันว่าทั้ง12บรรทัดเกิดเหมือนกันใน Forever
ยังไม่มีต้นฉบับครบสำหรับ Escaping Ban'ethil; อยู่ต้นคิวตรวจตามเลเวล
ข้อความที่ไม่รู้จัก ค่าลับ หรือไม่มี GUID จะไม่แสดงคำแปลเดา ไม่มีบริการแปลออนไลน์สด
ยังไม่ได้ทดสอบในเกม Windows หรือ Mac M2 และยังไม่ใช่คำแปลบทพูดครบทุกเควสต์
