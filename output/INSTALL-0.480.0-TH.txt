ติดตั้งผ่าน Launcher
เมื่อแพตช์ 0.480.0 เผยแพร่แล้ว ปิดเกมก่อนกด Update ใน Launcher และเปิดเกมใหม่ ตรวจว่าตัวแอดออนแสดง 0.480.0 การกดอัปเดต Launcher ยังไม่ยืนยันว่าลูกค้าทุกเครื่องติดตั้งสำเร็จแล้ว

ติดตั้งด้วย ZIP บน Windows หรือ Mac M2
1. ปิดเกม สำรองโฟลเดอร์ ForeverThai เดิมและค่าตั้งก่อน
2. แตก ZIP แล้วนำโฟลเดอร์ ForeverThai ไปไว้ใน Interface/AddOns ของ client Forever ที่ใช้เปิดเกมจริง ต้องได้ Interface/AddOns/ForeverThai/ForeverThai.toc ไม่ซ้อน ForeverThai อีกชั้น
3. เปิดเกมและตรวจว่ามี ForeverThai เพียงชุดเดียว หาก client มีเมนู AddOns ให้เปิดใช้งาน หากไม่มีให้ยึดโครงสร้างโฟลเดอร์ ไม่ต้องติดตั้งตัวแอดออนอื่นเพิ่มเพื่อโหลด
4. คงไฟล์ค่าตั้งเดิมไว้ ไม่ลบ SavedVariables ตัวเลือก Tracker ไทย/อังกฤษและการเชื่อม Questie ยังคงเดิม ผู้ไม่ใช้ Questie ใช้ Tracker ของเกมตามความสามารถเดิม
5. ทดลองเควสต์/Tracker หนึ่งจุด สกิลบนแถบหนึ่งอัน Talent หนึ่งอัน Profession หนึ่งอัน และ Item หนึ่งอัน

หากสกิลยังเป็นอังกฤษหรือกล่องสี่เหลี่ยม ให้ตรวจว่าโฟลเดอร์ Skills และ Fonts อยู่ครบจาก ZIP เดียวกัน ปิดและเปิดเกมใหม่ ไม่ลงเฉพาะไฟล์เควสต์ทับชุดเก่า บันทึกชื่อสกิล รุ่น client และภาพปัญหาสำหรับตรวจต่อ
