Alphaverse THAI SUB — แพ็กรวม 0.480.0

ชุดเดียวรวม Quest, Tracker, Questie integration, NPC subtitles, Skill, Talent, Profession, Item และฟอนต์ไทย ไม่ต้องลงสองแพ็กทับกัน ชื่อโฟลเดอร์และค่าตั้งเดิมยังใช้ ForeverThai แยกจาก Alphaverse XP

สิ่งที่เพิ่มในชุด MAIN44
เพิ่มข้อความระหว่างทำ/ส่งเควสต์ 186 ช่อง ใน 128 เควสต์เดิม เลเวล 56–60: คำแปลใหม่ที่ตรวจความหมาย 180 ข้อความ ใช้คำแปลเดิมตรงต้นฉบับ 5 ช่อง และข้อความซ้ำภายในชุด 1 ช่อง คงชุดเลเวล 1–55 ของ 0.479.0 และคำแปลเก่าทั้งหมดไว้ ไม่ใช่การอ้างว่าเพิ่ม 128 เควสต์ครบทุกช่องหรือแปลทั้งเกมครบแล้ว
ต้นฉบับ: Icy Veins Forever Database https://db.icy-veins.com/wow-forever/quests/ID ข้อความเควสต์ Blizzard Entertainment ตรวจตาม ID และช่วงข้อความเต็ม ค่า Added 70532 บนเว็บไม่ยืนยันว่าเควสต์แต่ละรายการเปิดเล่นใน Forever ปัจจุบัน ไม่มีการเดาชื่อผู้เล่น เผ่า คลาส หรือจำนวน 54 ช่องที่ชนิดตัวแปรยังไม่ชัดและข้อความจุดไข่ปลา 92102 ระหว่างทำยังคงเดิม

ติดตั้งผ่าน Launcher
เมื่อแพตช์ 0.480.0 เผยแพร่แล้ว ปิดเกมก่อนกด Update ใน Launcher และเปิดเกมใหม่ ตรวจว่าตัวแอดออนแสดง 0.480.0 การกดอัปเดต Launcher ยังไม่ยืนยันว่าลูกค้าทุกเครื่องติดตั้งสำเร็จแล้ว

ติดตั้งด้วย ZIP บน Windows หรือ Mac M2
1. ปิดเกม สำรองโฟลเดอร์ ForeverThai เดิมและค่าตั้งก่อน
2. แตก ZIP แล้วนำโฟลเดอร์ ForeverThai ไปไว้ใน Interface/AddOns ของ client Forever ที่ใช้เปิดเกมจริง ต้องได้ Interface/AddOns/ForeverThai/ForeverThai.toc ไม่ซ้อน ForeverThai อีกชั้น
3. เปิดเกมและตรวจว่ามี ForeverThai เพียงชุดเดียว หาก client มีเมนู AddOns ให้เปิดใช้งาน หากไม่มีให้ยึดโครงสร้างโฟลเดอร์ ไม่ต้องติดตั้งตัวแอดออนอื่นเพิ่มเพื่อโหลด
4. คงไฟล์ค่าตั้งเดิมไว้ ไม่ลบ SavedVariables ตัวเลือก Tracker ไทย/อังกฤษและการเชื่อม Questie ยังคงเดิม ผู้ไม่ใช้ Questie ใช้ Tracker ของเกมตามความสามารถเดิม
5. ทดลองเควสต์/Tracker หนึ่งจุด สกิลบนแถบหนึ่งอัน Talent หนึ่งอัน Profession หนึ่งอัน และ Item หนึ่งอัน

หากสกิลยังเป็นอังกฤษหรือกล่องสี่เหลี่ยม ให้ตรวจว่าโฟลเดอร์ Skills และ Fonts อยู่ครบจาก ZIP เดียวกัน ปิดและเปิดเกมใหม่ ไม่ลงเฉพาะไฟล์เควสต์ทับชุดเก่า บันทึกชื่อสกิล รุ่น client และภาพปัญหาสำหรับตรวจต่อ

ผลทางเทคนิคของแพ็กนี้
1860 กรณีตรงต้นฉบับ 6950 กรณีข้อความผิด/ตัวเลขผิด 3710 กรณีผิดช่วงเควสต์ ผ่าน โดยคงกรณีข้อความเดียวกันที่ของเดิมรองรับในช่องอื่นไว้ 10 กรณี
187 ไฟล์ runtime; 179 ไฟล์เดิมตรงทุกไบต์ รักษาไฟล์สกิล/ฟอนต์สำคัญ 28 ไฟล์และไฟล์ Fonts เดิม 125 ไฟล์ไว้ครบ ตรวจ Lua ตาม TOC 49 ไฟล์ สร้างภาพผ่าน BitmapLayer จริงในการจำลอง 744 ครั้ง ไม่พบภาษาไทยหลุดไปใช้ฟอนต์สด ตรวจพื้นที่รูปตัวอักษร 1459 ชุดและภาพตัวอย่าง 22 ภาพแล้ว
เพิ่มเฉพาะคำที่ฟอนต์เดิมยังไม่มี 663 ชิ้นและชุดการเรียงคำ 837 ชุดในภาพ 4 หน้า ไม่สร้างฟอนต์เก่าทั้งชุดใหม่ ไม่มี AI local
ผลทดสอบในเกม Windows และ Mac M2 ยังไม่มี จึงยังไม่ยืนยันพฤติกรรมใน client จริง ไม่ได้ติดตั้งหรือควบคุมเกมของผู้ใช้เพื่อทดสอบ ตัวป้องกัน Tracker หลายบรรทัดของ 8315/84213 ยังใช้ภาษาอังกฤษตามข้อจำกัดเดิม ไม่อ้างว่ารันชุดทดสอบ UI/Skill/NPC เก่าทั้งหมดใหม่
