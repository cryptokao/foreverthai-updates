ติดตั้งด้วยตนเองเมื่อพร้อมทดสอบ
1. ออกจากเกม สำรอง AddOns/ForeverThai เดิมและ SavedVariables ของ ForeverThai ก่อน
2. แตก ZIP แล้ววางโฟลเดอร์ ForeverThai ใน Interface/AddOns ของ client Forever ที่ใช้งาน ให้ไฟล์อยู่ที่ Interface/AddOns/ForeverThai/ForeverThai.toc
3. ใช้ ForeverThai ชุดเดียว อย่าแตกซ้อนโฟลเดอร์ และอย่าเอาแพ็กเควสต์อย่างเดียวทับแพ็กรวม
4. เข้าเกม ตรวจ Quest/Tracker, Skill บนแถบกด, Talent, Profession และ Item ในรอบเดียว หากพบปัญหาให้บันทึก OS/build เกมและข้อความที่ไม่แปล
5. ย้อนกลับโดยออกจากเกมและนำโฟลเดอร์สำรองคืน ไม่ต้องล้างค่าตั้งเดิม
Mac M2 ใช้ไฟล์ AddOn ชุดเดียวกันใน Interface/AddOns ของ client Forever ที่ติดตั้งไว้ แต่ยังไม่ได้ยืนยันในเกมจริงทั้ง Windows และ Mac M2
