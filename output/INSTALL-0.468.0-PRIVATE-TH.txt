วิธีติดตั้ง Windows
1. ปิดเกมก่อน สำรองโฟลเดอร์ Interface\AddOns\ForeverThai เดิมไว้
2. แตก ZIP จะได้โฟลเดอร์ ForeverThai หนึ่งโฟลเดอร์
3. วาง ForeverThai ใน Interface\AddOns ของ client Forever ที่ใช้อยู่จริง
   พาธไฟล์ต้องเป็น Interface\AddOns\ForeverThai\ForeverThai.toc
   ตรวจว่าไม่มีโฟลเดอร์ซ้อนเป็น ForeverThai\ForeverThai\ForeverThai.toc
4. ใช้ไฟล์ในแพ็กใหม่ครบชุดเดียว เก็บโฟลเดอร์ WTF และค่าตั้งเดิมไว้
5. เปิดเกม ตรวจเวอร์ชันจาก ForeverThai.toc ว่าเป็น 0.468.0
