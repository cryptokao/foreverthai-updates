Alphaverse THAI SUB — แพ็กรวมทดสอบส่วนตัว 0.477.0 (MAIN41)

รวม Quest, ตัวเลือก Tracker ไทย/อังกฤษ, การเชื่อม Questie, บทพูด NPC ที่แปลไว้เดิม, Skill, Talent, Profession, Item และฟอนต์ทั้งหมดใน ForeverThai โฟลเดอร์เดียว คงค่าตั้งและ SavedVariables เดิม แยกจาก Alphaverse XP

สิ่งที่เพิ่มจริง
เพิ่มคำแปลใหม่เก้าฟิลด์ในห้าเควสต์เดิม: 96381 ระหว่างทำ/สำเร็จ, 97198 ระหว่างทำ, 94350 ระหว่างทำ/สำเร็จ, 94358 ระหว่างทำ/สำเร็จ, 95928 ระหว่างทำ/สำเร็จ ไม่ใช่ห้าเควสต์ที่ยืนยันว่าครบทุกส่วน
94350 สำเร็จรองรับเฉพาะบทเต็มที่เขียน human paladin ไว้ตรง ๆ และ 94358 สำเร็จรองรับบทเต็มที่เขียน human ไม่เดาว่าเป็นเผ่าหรือคลาสผู้เล่น ไม่ใช้ UnitRace/UnitClass และไม่ขยายไปยังบทเผ่าหรือคลาสอื่นที่ยังไม่มีหลักฐาน
95284 สำเร็จยังมีตัวแทนคลาส และ 97198 สำเร็จยังมีตัวแทนชื่อที่ระบุบทบาทไม่ได้ จึงคงอังกฤษไว้

ติดตั้งด้วยตนเอง
1. ปิดเกม สำรองโฟลเดอร์ ForeverThai และค่าตั้งเดิมก่อน
2. แตก ZIP แล้วนำโฟลเดอร์ ForeverThai ไปไว้ใน Interface/AddOns ของ client Forever ที่ใช้งานจริง ให้ไฟล์อยู่ที่ Interface/AddOns/ForeverThai/ForeverThai.toc ไม่ซ้อน ForeverThai สองชั้น
3. ใช้แพ็กนี้ชุดเดียว เปลี่ยน runtime รุ่นเก่าทั้งโฟลเดอร์หลังสำรอง ไม่ลงชุดเควสต์กับชุดสกิลสองแพ็กทับกัน และไม่ลบ SavedVariables เดิม
4. เปิด client ใหม่ ตรวจว่า ForeverThai เปิดใช้งาน และเลือก Tracker ไทย/อังกฤษตามต้องการ Questie เป็นส่วนเสริม ความสามารถ Tracker ขึ้นกับ UI/client และ Addon ที่ใช้งาน
5. Mac M2 ใช้โครงสร้างโฟลเดอร์เดียวกันใน client ที่รองรับ แต่แพ็กนี้ยังไม่มีผลยืนยันจากการเล่นเกมจริงบน Windows หรือ Mac M2

ลองใช้งานหลังติดตั้ง
เปิดเควสต์กับ Tracker อย่างละหนึ่งจุด ชี้สกิลบนแถบกด เปิด Talent, Profession และชี้ Item ที่มีคำแปลเดิม หากเป็นอังกฤษหรือเป็นกล่อง ให้บันทึกรุ่น client/Addon ชื่อเควสต์หรือสกิล และหน้าจอที่พบปัญหา ไม่จำเป็นต้องล้างค่าตั้งก่อนตรวจ

ตรวจทางเทคนิคแล้ว
108 กรณีข้อความตรง, 324 กรณีปฏิเสธข้อความผิด รวมการเปลี่ยนเผ่า/คลาสที่เขียนในบทเต็ม และ 144 กรณีสลับเฟส รักษาคำแปลและรูปแบบจับคู่เดิม
runtime 173 ไฟล์: ไฟล์เดิม 168 ไฟล์คงไบต์เดิม เปลี่ยนเฉพาะรุ่น/แหล่งที่มา และเพิ่มไฟล์คำแปลกับข้อมูลฟอนต์สามไฟล์ ไฟล์ Skill/ฟอนต์สำคัญ 28 ไฟล์และฟอนต์เดิมทั้งหมด 120 ไฟล์คงไบต์เดิม
Lua ใน TOC 43 ไฟล์ผ่านตรวจไวยากรณ์และลำดับข้อมูลที่เปลี่ยน จำลอง BitmapLayer จริง 36 ครั้ง ไม่มีตัวไทยตกไปใช้ฟอนต์สด ตรวจภาพตัด glyph 195 จุดและภาพจำลองหนึ่งหน้า เพิ่มภาพคำเฉพาะที่ยังขาด 56 คำ ไม่สร้างฟอนต์เดิมทั้งชุดหรือใช้ AI บนเครื่อง
