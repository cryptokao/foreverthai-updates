ชุดนี้รวม Quest, Tracker ไทย/อังกฤษ, การเชื่อม Questie, บทพูด NPC ที่แปลไว้เดิม, Skill, Talent, Profession, Item และฟอนต์ไว้ใน ForeverThai โฟลเดอร์เดียว คงค่าตั้งและ SavedVariables เดิม แยกจาก Alphaverse XP

ติดตั้งด้วยตนเอง (ยังไม่ได้ติดตั้งหรือควบคุมเกมให้)
1. ปิดเกมก่อน สำรองโฟลเดอร์ ForeverThai และไฟล์ค่าตั้งเดิมไว้
2. แตก ZIP จะได้โฟลเดอร์ ForeverThai นำไปไว้ใน Interface/AddOns ของ client Forever ที่ใช้งานจริง ให้ไฟล์อยู่ที่ Interface/AddOns/ForeverThai/ForeverThai.toc ไม่ซ้อน ForeverThai สองชั้น
3. ใช้แพ็กนี้ชุดเดียวสำหรับภาษาไทย หากมี ForeverThai รุ่นเก่า ให้เปลี่ยนโฟลเดอร์ runtime ทั้งชุดหลังสำรอง ไม่ลงชุดเควสต์และชุดสกิลสองแพ็กทับกัน และไม่ลบ SavedVariables เดิม
4. เปิด client ใหม่ ตรวจว่า ForeverThai เปิดใช้งาน แล้วตรวจเควสต์และการตั้ง Tracker ไทย/อังกฤษตามตัวเลือกเดิม Questie เป็นส่วนเสริม ไม่จำเป็นสำหรับหน้าต่างเควสต์ของ ForeverThai; ความสามารถ Tracker ขึ้นกับ UI/client และ Addon ที่ใช้
5. Mac M2 ใช้โครงสร้างโฟลเดอร์เดียวกันใน client ที่รองรับ แต่ยังไม่มีผลทดสอบในเกม Mac M2 หรือ Windows สำหรับแพ็กนี้ จึงยังรับรองผลจริงไม่ได้

ตรวจหลังติดตั้ง
ลองเปิดเควสต์หนึ่งจุดและ Tracker หนึ่งจุด ชี้สกิลบนแถบกด เปิด Talent, Profession และชี้ Item ที่มีคำแปลเดิม หากแสดงอังกฤษหรือเป็นกล่อง ให้บันทึกเวอร์ชัน client/Addon ชื่อเควสต์หรือสกิล และตำแหน่งหน้าจอ ไม่จำเป็นต้องล้างค่าตั้งก่อนตรวจ

ผลทางเทคนิคและข้อจำกัด
ตรวจข้อความตรงต้นฉบับทั้งประโยค ตัวเลข เงื่อนไข ชื่อ NPC/ไอเท็ม/สถานที่ พร้อมตรวจว่าคำแปลเดิมและรูปแบบจับคู่เดิมยังอยู่ ผ่าน 152 กรณีรับข้อความ, 396 กรณีปฏิเสธข้อความผิด และ 104 กรณีสลับเฟส
ไฟล์ runtime 161 ไฟล์: ไฟล์เดิม 156 ไฟล์คงไบต์เดิมทั้งหมด เปลี่ยนเฉพาะข้อมูลรุ่น/แหล่งที่มา และเพิ่มไฟล์คำแปลกับข้อมูลฟอนต์ 3 ไฟล์ ไฟล์ Skill/ฟอนต์สำคัญ 28 ไฟล์และฟอนต์เดิมทั้งหมด 116 ไฟล์คงไบต์เดิม ตรวจ Lua ใน TOC 35 ไฟล์และจำลอง BitmapLayer จริง 52 ครั้ง ไม่มีข้อความไทยตกไปใช้ฟอนต์สด ตรวจภาพตัด glyph 203 จุดและดูภาพจำลองแล้ว
