รวม Quest, ตัวเลือก Tracker ไทย/อังกฤษ, การเชื่อม Questie, บทพูด NPC ที่แปลไว้เดิม, Skill, Talent, Profession, Item และฟอนต์ทั้งหมดใน ForeverThai โฟลเดอร์เดียว คงค่าตั้งและ SavedVariables เดิม แยกจาก Alphaverse XP

86792 เป้าหมาย Thinning Their Forces: จำนวน 6/4/2 ตรวจจากหน้าเควสต์ของรหัสนี้โดยตรง ไม่เดาจากลำดับตารางเป้าหมาย

ติดตั้งด้วยตนเอง
1. ปิดเกม สำรองโฟลเดอร์ ForeverThai และค่าตั้งเดิมก่อน
2. แตก ZIP แล้วนำโฟลเดอร์ ForeverThai ไปไว้ใน Interface/AddOns ของ client Forever ที่ใช้งานจริง ให้ไฟล์อยู่ที่ Interface/AddOns/ForeverThai/ForeverThai.toc ไม่ซ้อน ForeverThai สองชั้น
3. ใช้แพ็กนี้ชุดเดียว เปลี่ยน runtime รุ่นเก่าทั้งโฟลเดอร์หลังสำรอง ไม่ลงชุดเควสต์กับชุดสกิลสองแพ็กทับกัน และไม่ลบ SavedVariables เดิม
4. เปิด client ใหม่ ตรวจว่า ForeverThai เปิดใช้งาน และเลือก Tracker ไทย/อังกฤษตามต้องการ Questie เป็นส่วนเสริม ความสามารถ Tracker ขึ้นกับ UI/client และ Addon ที่ใช้งาน
5. Mac M2 ใช้โครงสร้างโฟลเดอร์เดียวกันใน client ที่รองรับ แต่แพ็กนี้ยังไม่มีผลยืนยันจากการเล่นเกมจริงบน Windows หรือ Mac M2

ลองใช้งานหลังติดตั้ง
เปิดเควสต์กับ Tracker อย่างละหนึ่งจุด ชี้สกิลบนแถบกด เปิด Talent, Profession และชี้ Item ที่มีคำแปลเดิม หากเป็นอังกฤษหรือเป็นกล่อง ให้บันทึกรุ่น client/Addon ชื่อเควสต์หรือสกิล และหน้าจอที่พบปัญหา ไม่จำเป็นต้องล้างค่าตั้งก่อนตรวจ
