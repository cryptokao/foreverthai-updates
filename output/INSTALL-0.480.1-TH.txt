ForeverThai 0.480.1 — แพตช์แก้ Skill / Talent / Profession / Item ไม่แสดงภาษาไทย

สาเหตุที่ตรวจพบ: เกม 1.60.1 build 70959 แต่ระบบตรวจความเข้ากันได้เดิมอนุญาตเฉพาะ build 70862/70888/70938 จึงปิดโมดูลคำแปลทั้งหมดแม้มีไฟล์ครบ แพตช์นี้รองรับ build ตัวเลขในสาขา 1.60.1 / interface 16001 / enUS และยังตรวจชื่อ ข้อความ และค่าตัวเลขก่อนแสดงคำแปลเดิม

อัปเดตผ่าน Launcher: ปิดเกมก่อน กด Update แล้วเปิดเกมใหม่ ตรวจเวอร์ชัน ForeverThai เป็น 0.480.1 หากยังไม่แสดง ใช้ /alphathai status แล้วแจ้งผลพร้อมชื่อสกิลหรือไอเท็ม ระบบไม่บังคับเปิดตัวเลือกที่ผู้ใช้เคยปิดไว้

ติดตั้งเอง: ปิดเกม แตก ZIP ให้ได้โฟลเดอร์ ForeverThai ภายใน Interface/AddOns โดยไม่ซ้อน ForeverThai/ForeverThai สำรองโฟลเดอร์เดิมก่อนแทนที่ ไม่ต้องลบ SavedVariables และไม่ต้องลงแอดออนแปลสองชุดทับกัน

ชุดเดียวรวม Quest, Tracker/Questie, บทพูด NPC ที่มีคำแปลแล้ว, Skill, Talent, Profession, Item และฟอนต์เดิมทั้งหมด ไม่ได้เพิ่มคำแปลเควสต์ใหม่ในแพตช์นี้ และไม่ได้อ้างว่าแปลครบทั้งเกม

ผ่านการจำลองโหลด Lua 49 รายการและการทดสอบ Skill/UI 9 กรณีบน build 70959 รวมสกิลบนแถบกด ทาเลนต์ ไอเท็มและวิชาชีพ ยังไม่ได้ยืนยันการแสดงผลในเกมจริงบน Windows หรือ Mac M2
