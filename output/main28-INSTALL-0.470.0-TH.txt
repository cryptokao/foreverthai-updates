ติดตั้ง Windows
1. ปิดเกมและสำรอง Interface\AddOns\ForeverThai เดิม
2. แตก ZIP แล้ววาง ForeverThai ใน Interface\AddOns ของ client ที่เปิดเล่นจริง
3. พาธต้องลงท้ายด้วย Interface\AddOns\ForeverThai\ForeverThai.toc อย่าวาง ForeverThai ซ้อนกัน
4. ใช้ ForeverThai เพียงชุดเดียว เก็บ WTF และค่าตั้งเดิมไว้
5. ตรวจ ForeverThai.toc เป็น 0.470.0 แล้วเปิดเกม
