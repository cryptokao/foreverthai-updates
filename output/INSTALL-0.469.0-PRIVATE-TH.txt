ติดตั้ง Windows
1. ปิดเกมและสำรองโฟลเดอร์ Interface\AddOns\ForeverThai เดิม
2. แตก ZIP แล้ววางโฟลเดอร์ ForeverThai ใน Interface\AddOns ของ client ที่ใช้เล่นจริง
3. พาธต้องลงท้ายด้วย Interface\AddOns\ForeverThai\ForeverThai.toc
   อย่าวางซ้อนเป็น ForeverThai\ForeverThai\ForeverThai.toc
4. ใช้แพ็ก ForeverThai เพียงชุดเดียว เก็บ WTF และค่าตั้งเดิมไว้
5. ตรวจ ForeverThai.toc ว่าเป็น 0.469.0 แล้วเปิดเกม

Mac M2
ใช้โฟลเดอร์ ForeverThai จาก ZIP เดียวกัน วางใน Interface/AddOns ของ client
ที่เปิดเล่นจริง หากใช้ Wine/CrossOver ให้เลือกโฟลเดอร์เกมในชุดที่ใช้นั้น
คงชื่อไฟล์และตัวพิมพ์ตาม ZIP ไว้ ไฟล์ข้อมูล Lua/TGA ใช้ร่วมกันได้
ยังไม่มีผลทดสอบในเกมจริงบน Mac M2 สำหรับแพ็กนี้

การตรวจทางเทคนิค
- อ่านกลับ ZIP ครบ 151 ไฟล์ ไม่มีชื่อซ้ำ รายการโหลด TOC ครบและ Lua ทั้ง 28 ไฟล์ตรวจไวยากรณ์ผ่าน
- ไฟล์เดิม 146 ไฟล์เหมือน 0.468.0 ทุกไบต์ เปลี่ยนเพียงเวอร์ชัน/เอกสารที่มา และเพิ่มไฟล์ข้อมูล 3 ไฟล์
- คงชุด Skill/Talent/Profession/Item รวมถึงไฟล์สกิล/ฟอนต์ที่ต้องรักษา 28 รายการ และฟอนต์เดิม 113 รายการ
- ทดสอบต้นฉบับ/ตัวแปร 4 รูปแบบ: จับคู่ถูก 100 กรณี พร้อม short-race อีก 1 กรณี
  ปฏิเสธข้อความ/ตัวแปรผิด 1,204 กรณี และผิดเควสต์/ผิดช่วงอีก 200 กรณี
- ประกอบแพ็กแล้วจำลอง BitmapLayer ด้วยฟอนต์จริง 100 ครั้ง ไม่มีข้อความไทยตกไปใช้ live font
- เพิ่มฟอนต์เฉพาะ 45 ภาพคำใน Thai99.tga หนึ่งหน้า และ run ใหม่ 69 รายการ
- ไม่เปลี่ยน Match, Tracker, Questie integration, NPC engine หรือระบบ Skill เดิม

ข้อจำกัดที่ต้องทราบ
- เป็นชุดทดสอบสำหรับข้อความอังกฤษของ Forever; ข้อมูล/fixture อ้างอิง build 70938
