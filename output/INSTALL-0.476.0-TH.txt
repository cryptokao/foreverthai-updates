Alphaverse THAI SUB — แพ็กรวมทดสอบส่วนตัว 0.476.0 (MAIN40)

รวม Quest, ตัวเลือก Tracker ไทย/อังกฤษ, การเชื่อม Questie, บทพูด NPC ที่แปลไว้เดิม, Skill, Talent, Profession, Item และฟอนต์ทั้งหมดใน ForeverThai โฟลเดอร์เดียว คงค่าตั้งและ SavedVariables เดิม แยกจาก Alphaverse XP

สิ่งที่เพิ่มจริง
เพิ่มสองฟิลด์ที่เดิมว่างในสองเควสต์เดิม: 93362 ข้อความระหว่างทำ และ 93601 ข้อความส่งเควสต์ เป็นคำแปลใหม่หนึ่งฟิลด์และใช้คำแปลเดิมที่ตรวจแล้วหนึ่งฟิลด์ ไม่ใช่สองเควสต์ที่ยืนยันว่าครบทุกส่วน
93362 ระหว่างทำใช้คำแปลเดียวกับ 5102 ซึ่งตรงต้นฉบับเดียวกัน ส่วนข้อความสำเร็จ 93362 ยังมีตัวแทนชื่อที่ระบุบทบาทไม่ได้ จึงคงอังกฤษไว้
93601 รองรับเฉพาะบทเต็มที่เขียน Night Elf ไว้ตรง ๆ ไม่เดาว่าเป็นเผ่าผู้เล่น ไม่แทน UnitRace และไม่ขยายการจับคู่ไปยังข้อความ Human หรือ Orc ที่ไม่มีหลักฐาน

ใช้ข้อความแต่ละรหัสและเฟสใน Icy Veins Forever Database ข้อความเกมเป็นของ Blizzard Entertainment หน้าเว็บระบุว่าเป็นฐานข้อมูล early access และ Added in patch 1.60.1.70532 ซึ่งไม่ยืนยันว่าทุกข้อความเปิดใช้งานอยู่ใน client ปัจจุบัน แหล่งที่มา ลายนิ้วมือข้อความ และคำแปลอยู่ในหลักฐาน MAIN40 ไม่อ้างว่าแปลทั้งเกมครบ 100%

ติดตั้งด้วยตนเอง
1. ปิดเกม สำรองโฟลเดอร์ ForeverThai และค่าตั้งเดิมก่อน
2. แตก ZIP แล้วนำโฟลเดอร์ ForeverThai ไปไว้ใน Interface/AddOns ของ client Forever ที่ใช้งานจริง ให้ไฟล์อยู่ที่ Interface/AddOns/ForeverThai/ForeverThai.toc ไม่ซ้อน ForeverThai สองชั้น
3. ใช้แพ็กนี้ชุดเดียว เปลี่ยน runtime รุ่นเก่าทั้งโฟลเดอร์หลังสำรอง ไม่ลงชุดเควสต์กับชุดสกิลสองแพ็กทับกัน และไม่ลบ SavedVariables เดิม
4. เปิด client ใหม่ ตรวจว่า ForeverThai เปิดใช้งาน และเลือก Tracker ไทย/อังกฤษตามต้องการ Questie เป็นส่วนเสริม ความสามารถ Tracker ขึ้นกับ UI/client และ Addon ที่ใช้งาน
5. Mac M2 ใช้โครงสร้างโฟลเดอร์เดียวกันใน client ที่รองรับ แต่แพ็กนี้ยังไม่มีผลยืนยันจากการเล่นเกมจริงบน Windows หรือ Mac M2

ลองใช้งานหลังติดตั้ง
เปิดเควสต์กับ Tracker อย่างละหนึ่งจุด ชี้สกิลบนแถบกด เปิด Talent, Profession และชี้ Item ที่มีคำแปลเดิม หากเป็นอังกฤษหรือเป็นกล่อง ให้บันทึกรุ่น client/Addon ชื่อเควสต์หรือสกิล และหน้าจอที่พบปัญหา ไม่จำเป็นต้องล้างค่าตั้งก่อนตรวจ

ตรวจทางเทคนิคแล้ว
24 กรณีข้อความตรง, 78 กรณีปฏิเสธข้อความผิด รวมการเปลี่ยนเผ่าและชื่อ NPC และ 32 กรณีสลับเฟส รักษาคำแปลเก่า รูปแบบจับคู่เดิม และฟิลด์ที่ยังค้างไว้

Lua ใน TOC 41 ไฟล์ผ่านตรวจไวยากรณ์และลำดับข้อมูลที่เปลี่ยน จำลอง BitmapLayer จริงแปดครั้ง ไม่มีตัวไทยตกไปใช้ฟอนต์สด ตรวจภาพตัด glyph 51 จุดและภาพจำลองหนึ่งหน้า เพิ่มภาพคำเฉพาะที่ยังขาด 12 คำ ไม่สร้างฟอนต์เดิมทั้งชุดหรือใช้ AI บนเครื่อง
